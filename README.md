# Juniper Home Cleaning

Juniper Home Cleaning helps customers understand their cleaning cost before they book. Build a tailored estimate, review every charge, and keep a clear quote for later.

## Build an estimate

Choose the cleaning service that suits the home:

- Standard clean for a regular refresh
- Deep clean for a fuller reset
- Move-out clean before handing over the keys

Add bedrooms, bathrooms, home size, preferred timing, and any finishing touches such as oven cleaning, refrigerator cleaning, interior windows, or laundry refresh. The estimate updates with an itemized USD price breakdown as details are selected.

## Review the quote

Once the home and visit details are complete, enter a name, email address, and preferred date to create a clear estimate. The quote includes a reference number, service details, pricing breakdown, and total.

You can copy the quote, print or save it as a PDF, and use the request action to see the next step. The request action is intentionally a demonstration: it confirms that no request or personal information is sent.

## Designed for everyday planning

The experience works from phone to desktop, keeps pricing visible while customers make choices, and saves an unfinished estimate on the current device so a customer can return to it later. Prices are estimates; final pricing and availability are confirmed after review.
